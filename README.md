# Unraid Plugins

A collection of small plugins and WebGUI enhancements for Unraid.

## CPU Tile Summary

Shows CPU power, temperature, and overall load in the collapsed Processor tile description. The source, installer, and plugin details are in [`cpu-tile-summary/`](cpu-tile-summary/).

Install from **Plugins → Install Plugin**:

```text
https://raw.githubusercontent.com/shiftylilbastrd/Unraid-plugins/main/cpu-tile-summary/cpu-tile-summary.plg
```

## Corsair PSU Center with Dashboard tile

Auto-detects supported Corsair PSUs, provides the full monitoring and control page, and adds a native Dashboard tile. Details and migration steps are in [`corsairpsucenter/`](corsairpsucenter/).

Install from **Plugins → Install Plugin**:

```text
https://raw.githubusercontent.com/shiftylilbastrd/Unraid-plugins/main/corsairpsucenter/corsairpsucenter.plg
```
