# Corsair PSU Statistics (legacy)

This folder contains the earlier dashboard-only fix for giganode's Corsair PSU Statistics plugin. It is superseded by the combined Corsair PSU Center plugin, which includes automatic PSU detection, a full monitoring/control page, and a Dashboard tile.

Use the combined plugin instructions in [../corsairpsucenter/README.md](../corsairpsucenter/README.md). Remove Corsair PSU Statistics before installing the combined plugin so both plugins do not poll the same PSU.
